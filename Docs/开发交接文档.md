# 开发交接文档（跨机器续开发指南）

> 更新：2026-11-08。本文解决"换一台机器继续开发"的问题：环境搭建、常用命令、迭代循环、坑位索引。
> 深度细节见 `Docs/多平台构建指南.md`（含全部坑位记录），美术需求见 `Docs/美术需求总览.md`，UI 节点契约见 `Docs/UIContract.md`。

## 1. 项目概况

| 项 | 值 |
|---|---|
| 仓库 | `github.com/liu3122/tuanjiesimplegame`（main 分支） |
| 引擎 | **团结引擎 2022.3.62t16**（Tuanjie Hub 安装，需 **Mini Game Build Support** 与 **WebGL Build Support** 模块） |
| 热更 | HybridCLR（首次任何构建会自动安装，`CIBuild.EnsureHybridCLRInstalled`；失败走 `CIBuild.InstallHybridCLFromLocal` 兜底） |
| 异步 | UniTask 2.5.11（**嵌入式包** `Packages/com.cysharp.unitask`，随仓库走，无需网络） |
| 资源 | YooAsset 3.0.5（`Packages/com.tuyoogame.yooasset`）+ 微信扩展（`Assets/YooAssetMiniGame`） |
| 微信 SDK | WX-WASM-SDK-V2（小程序转换插件 1.3.14 / IDE 2.02.x） |
| 配置 | Luban（`LubanWorkspace/`，xlsx 数据 + xml 定义） |
| 服务端 | ASP.NET（`Server/`，sqlite 持久化 `simplegame.db`） |

**架构速览**：AOT 侧 `Assets/GameFramework/GameApp.cs`（引导：YooAsset 初始化 → AOT 元数据 → 热更 DLL → `EnterHotUpdate` 反射+协程驱动）；热更侧 `Assets/HotUpdateScripts/`（业务/UI/ApiClient/LoginBridge，**不可引用 Assembly-CSharp**）；平台桥 `Assets/HotUpdateScripts/Platform/`（MINIGAME/STEAM 宏选实现）。

## 2. 新机器环境搭建

1. **克隆**（GitHub 需代理，本机配置为 `http://127.0.0.1:7897`，按新机器实际代理改）：
   `git clone https://github.com/liu3122/tuanjiesimplegame.git`
2. **团结引擎**：Tuanjie Hub 装 2022.3.62t16 + Mini Game/WebGL Build Support，用本仓库直接打开（UniTask 是嵌入式包，packages-lock 已含，**无需装包**）。
3. **微信开发者工具**：安装后设置 → 安全 → **开启服务端口**（CLI 前提）；打开过一次任意项目完成初始化。
4. **本地 CDN**（小游戏运行时资源源）：
   ```bat
   mkdir C:\tmp\cdnroot && cd C:\tmp\cdnroot
   mklink /J CDN <仓库>\Build\Bundles\MiniGame\DefaultPackage\<最新版本目录>
   python -m http.server 80
   ```
   游戏侧常量 `GameApp.RemoteHostURL = http://127.0.0.1/CDN`（与导出时 `DATA_CDN` 补写值必须同前缀）。
5. **游戏服务端**：`cd Server && dotnet run --urls http://127.0.0.1:5188`（登录/钱包/开箱全走它）。
6. **首次产物生成**（Build/ 不入库，新机器是空的）：
   - 先跑 `CIBuild.BuildMinigameBundles`（生成资源包，见下节命令）
   - 再跑 `WXMinigameExport.Run`（生成小游戏工程 + wasm）

## 3. 三条开发循环（核心！）

### A. 编辑器内开发（日常业务/UI）
直接 Unity Play。配置模拟走 EditorSimulate（`EditorSimulateBuildHelper`），不依赖 CDN/服务端（登录失败会 Toast 但可调 UI）。

### B. 纯热更侧改动 → 分钟级迭代（**无需重新导出**）
改 `Assets/HotUpdateScripts/**`（业务/UI/ApiClient）后：
```
Unity -batchmode -quit -executeMethod CIBuild.BuildMinigameBundles
:: 切 junction 到新版本目录（见上），然后开发者工具点【编译】
```
原理：wasm 不含热更代码，运行时全从 CDN 拉新 bundle。

### C. AOT 侧改动 → 完整导出（~10 分钟）
改 `GameApp`/SDK/新程序集/宏/`link.xml` 后：
```
set WX_APPID=wx69b20e32966d1a6d
Unity -batchmode -quit -executeMethod WXMinigameExport.Run
robocopy Build\wx\minigame Build\wx\minigame_dev /MIR
```
导出脚本自动：注入 DOM shim → **补写 DATA_CDN**（`WX_CDN` 环境变量可覆盖，真机预览用 `http://<局域网IP>/CDN`）→ 补拷 StreamingAssets。

### 常用命令速查
| 事 | 命令/入口 |
|---|---|
| 只重建资源包 | 菜单 `Build/CI/WeixinMiniGame Bundles Only` 或 `-executeMethod CIBuild.BuildMinigameBundles` |
| 完整出包 | 菜单 `Build/CI/WX 导出小游戏工程` 或 `-executeMethod WXMinigameExport.Run` |
| 多平台 CI | `Tools/ci/build_all.sh`（`-ciTarget win/steam/android/webgl/minigame/ios`） |
| Luban 配置 | `LubanWorkspace\gen.bat`（代码→HotUpdateScripts/Gen，json→AssetRaw/Config）；服务端 `gen_server.bat` |
| UI prefab 烘焙 | 菜单 `Build/UI/Bake UI Prefabs`（改布局后手动烘+提交，契约校验会拦忘烘） |
| 开发者工具 CLI | PowerShell 直调（中文路径经 cmd 会乱码）：`& 'D:\...\微信web开发者工具\cli.bat' auto --project <minigame_dev> --auto-port 9420` |

## 4. 微信开发者工具要点

- 工作区用 `Build/wx/minigame_dev`（robocopy 镜像自 `minigame`），避免导出目录被工具锁。
- 该版本 **automation 桥对小游戏无响应**（reLaunch/console 事件全超时）——看日志直接用 GUI：菜单 界面→调试器 开 Console；验证资源加载用 **Network 面板**（bundle 200 即通）。
- Console 里 `[GameApp]`/`[HotUpdate]` 前缀是游戏日志；`Unable to open archive` 类错误看 §5 坑位索引。

## 5. 坑位索引（详见 多平台构建指南.md 对应章节）

| 关键词 | 一句话根因 |
|---|---|
| `Unable to open archive file: http://…bundle` | 导出后 game.js 的 `DATA_CDN` 为空 → wx 下载层 URL→本地映射损坏（导出脚本已自动补写，勿手删） |
| 运行时执行旧逻辑 / 程序集大小对不上 | `WXMinigameExport` 不重建资源包——改热更代码必须先跑 `BuildMinigameBundles` |
| 热更入口改 IEnumerator 后无动作 | `EnterHotUpdate` 需 `StartCoroutine` 驱动（已修，改动时留意） |
| `ExecutionEngineException: …TYPEREF fail` | 热更代码引用了被 AOT 裁剪的类型（如 `YieldAwaitable`）→ Assembly.Load 即崩；**新库必须进 AOT + link.xml 整包保留**（UniTask 已配好） |
| `HttpClient` await 挂死 | WASM 无 System.Net——WebGL 分支已走 UnityWebRequest+UniTask |
| InputField 不能输入 | WASM 无键盘事件，用 `WXKeyboard.Bind(input)`（已挂在 LoginScreen） |
| `WebGL platform does not support synchronous loading` | WebGL 禁同步资源加载——一律 LoadAssetAsync/协程 |
| 配置表红字 Location is invalid | 加载列表与 Luban 实际表不符（tbskill 已删，新增表记得同步列表） |

## 6. 当前状态与遗留待办

**已全链路验证（2026-11-08）**：引擎 → YooAsset/CDN → AOT 元数据 → 热更 DLL（UniTask）→ 13 配置表 → 微信键盘 → 登录（5188 往返）→ 主界面。

遗留（优先级序）：
1. UI 美术图缺失：`icon_coin`/`btn_blue` 等（`[UITheme] Sprite 不存在` 降级占位；资产清单见美术需求总览）
2. 微信登录接入：code2session（服务端 `/api/auth/weixin` 端点待实现 + 客户端 LoginBridge 换真实现）
3. 真机预览：`WX_CDN=http://<局域网IP>/CDN` 重新出包
4. netstandard AOT 补充元数据警告（非阻塞）
5. 包内/CDN 双份 bundle 冗余 ~2.2MB（做「首包包内直读」时消化；届时研究 WXAssetBundle 本地路径 + BuiltinCatalog 方案）
