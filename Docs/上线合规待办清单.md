# 上线合规待办清单（软著 → 微信小游戏上线 → 版号）

> 生成于 2026-11，基于：企业为老执照公司（经营异常 + 税务长期未申报 + 无统一社会信用代码），
> 游戏为纯广告变现（IAA）微信小游戏，无内购。
>
> 核心路线：**IAA 上线不需要版号**（软著 + 备案即可）；版号作为可选并行线（内购/App 发行才必须）。

## 三条线总览

| 线 | 内容 | 依赖 | 谁干 |
|---|---|---|---|
| A 主体修复 | 换照/年报/税务/对公户 | 无，立即开始 | 线下跑腿（你） |
| B 软著 | 定名/材料/提交 | A 的换照（新执照） | 你准备材料 |
| C 游戏合规改造 | 文案/敏感词/概率公示/适龄/隐私/防沉迷 | 无，可与 A 完全并行 | 代码活（可交给开发/Agent） |
| D 备案上线 | 小游戏备案 + 提审 | A 完成 + B 拿证 + C 完成 | 你 |
| E 版号（可选） | 出版单位 + 材料包 + 整改预期 | A 的无外资核查 + B 软著 | 你 + 出版社 |

时间线（串行关键路径约 6~8 周上线；版号另计 3~6 个月+）：

```
第1周    A0.1 换照一趟窗口（新信用代码+联络员+经营范围）
第1-2周  A0.2 补年报→移出异常 ‖ A0.3 税务线启动 ‖ C 全程并行
第2-4周  A0.3 补申报→罚款→解非正常 ‖ B 材料准备
第3-5周  A0.4 对公账户（先查状态再开/销重开）
第4-6周  B 软著/电子版权拿证
第6-8周  D 备案 → 提审 → 上线（IAA）
第8周起  E 版号（如需）
```

## A 线：主体修复（第 0 步，全部的前置）

### A0.1 换照（最先，一次窗口办三件事）
- [ ] 换发"一照一码"营业执照，领 18 位统一社会信用代码
- [ ] 同趟办理：工商联络员重置（换成现用手机号，补年报要收验证码）
- [ ] 同趟办理：经营范围加"软件开发；信息技术服务"（经营异常名录不拦变更登记）
- 带：营业执照正副本、组织机构代码证、税务登记证（丢了先在 gsxt 发免费遗失公告）、法人身份证（代办加委托书+经办人身份证）
- 免费，当场~3 个工作日

### A0.2 工商：年报异常
- [ ] gsxt.gov.cn → 企业信息填报 → 逐年补报漏掉的年报（没经营就如实填零）
- [ ] 补报后提交"移出经营异常名录申请"（法定 5 个工作日内核实）
- ⚠️ 若列入异常已满 3 年 → 已升级严重违法失信名单，需走信用修复流程（先查列入日期）
- 免费

### A0.3 税务：长期未申报（约 2~4 周）
- [ ] 电子税务局 APP 法人实名认证（认不了跑大厅）
- [ ] 大厅/专管员打"逾期未申报属期"清单（别自己猜属期）
- [ ] 批量补零申报：增值税、企业所得税、附加（没经营全零；没员工不涉及个税）
- [ ] 缴罚款（未按期申报 200 元起；主动问首违免罚政策）
- [ ] 申请解除非正常户；窗口主动出示新执照同步统一信用代码
- ⚠️ 当年领过发票的先缴销发票

### A0.4 对公账户（约 1~2 周）
- [ ] **先查状态**：① 翻老资料（开户许可证/U盾/印鉴卡/对账单/验资报告——2014.3 前注册且有验资报告≈肯定开过）② 问当年代办 ③ 电子税务局查"存款账户账号报告"
- [ ] 兜底：去目标银行让柜面查公司名下旧账户/久悬户（与开户合并成一次跑腿）
- [ ] 从未开户 → 开基本户：约民生/招商/平安等小微友好行；法人面签；带新执照+三章+身份证；可能上门核查场地（无场地用代账挂靠地址或说明线上经营）；费用 0~200+，多家比价
- [ ] 久悬户 → 原行销户（清余额+三章+法人到场）→ 再开新户；名下久悬不销，别家开不了
- ⚠️ 公章丢失：gsxt 公示遗失 → 公安备案刻新章（1~3 天），没有三章开不了户

### A0.5 版号前置核查（顺手，5 分钟）
- [ ] 查股权结构**无外资**（版号硬要求，现在确认省得以后被动）

## B 线：软著（著作权人 = 修复后的公司）

- [ ] **B1 定名**：游戏正式名 + 软著全称（如《宝箱商人游戏软件》V1.0）+ 简称；与微信小游戏名一致；顺手查商标
- [ ] **B2 源程序材料**：前 30 页 + 后 30 页、每页 ≥50 行；从自有代码选（`Assets/HotUpdateScripts/` + `Server/`），**避开 HybridCLR/YooAsset/Luban/UniTask 等开源框架代码页**
- [ ] **B3 文档材料**：用户操作手册或设计说明书（60 页或前 30 后 30），基于 README/Docs + 游戏截图拼装
- [ ] **B4 提交渠道**（二选一）：
  - 中国版权保护中心自报：免费，约 1~2 个月
  - 电子版权认证证书：10~15 天，微信备案同样认可（着急上线选这个）
- 前置：A0.1 新执照下来后才能以公司名义提交
