## 一、这是什么游戏

**一句话**：竖屏手游《宝箱商人》——「Deal or No Deal」式开箱博弈 + 拍卖经济 + 1v1/多人实时对抗。玩家买 20 格宝箱，逐格排除金额，期望值（EV）实时变化，银行家随时报价——**卖，还是赌下去？**

| 玩法 | 一句话 | 视觉重点 |
|---|---|---|
| 开宝箱（核心） | 20 格排除、银行家报价、9 种技能 | 格子四态、宝箱、银行家形象、技能图标 |
| 拍卖行 | 挂拍竞价、一口价、机器人对手 | 价签、列表行底板 |
| 抢宝房（竞宝） | 多人实时抢 20 格奖池（明抢/盲抢） | 红包格、房卡、倒计时 |
| 镜像对决 / 竞宝房 | 1v1 同箱对开，赢家通吃 | VS 对抗感、双方头像位 |
| 成长线 | 等级 1~10、天梯 Elo、周赛季、宅邸改造、好友私房 | 段位徽章、宅邸两态、好友码 |

## 二、怎么用这份文档（工作流）

1. **第 0 批先出 3 张风格样张**（A1 登录 / A2 主大厅 / A5 开宝箱，可直接粘贴的提示词见第十章），多轮挑选定稿——这张定稿就是后续所有图的**风格锚点**（MJ 用 `--sref`，即梦/GPT-4o 用参考图上传）。
2. **批量出全套界面效果图**：按第四、五章逐屏粘贴提示词（每条前面拼上第三章【风格头】）。效果图的作用 = **布局基准 + 风格基准**，AI 图里的文字一律视为占位（正式文案由程序渲染，多语言安全）。
3. **散件切图单独出**（第六、七章，透明底）：效果图里的按钮/面板/格子不能直接切进引擎用，需按命名与规格单独生成或从定稿效果图手工切图。
4. **逐屏重搭 UGUI**：照效果图在 Unity 里新建 prefab（沿用现有节点命名与绑定约定，逐屏替换烘焙 UI），散件按名接入。
5. 效果图本身**不进资源包**（建议存 `Docs/参考图/`，不进 YooAsset 收集目录）；进包的只有第六、七章切图散件。

## 三、风格锚点与统一提示词

- **基调**：明快卡通休闲——明亮渐变底、圆润 Q 版元素、胖萌宝箱、色彩明快柔和（原「暗金赌场」厚重风已废弃）
- **色板**：背景 暖奶油 `#F7F0DC`→天蓝渐变、面板 米白 `#FFFDF6`（圆角+柔和投影）、主色 橙金 `#FFB932`、胜利/确认 草绿 `#6FD98C`、危险 珊瑚红 `#FF7B6B`、信息 天蓝 `#5BC8F5`、文字 深棕 `#4A3B28`、次级文字 暖灰 `#9C917F`
- **品质色**（道具/角色通用，浅底可见版）：暖灰白 `#B9B2A4` / 绿 `#6FD98C` / 蓝 `#5BC8F5` / 紫 `#9B8EC4` / 橙金 `#FFB932`
- **画幅**：竖屏 1080×1920；效果图 9:16，切图按 2x 出

**【风格头·中文】**（每条提示词前拼接）：

```

```

**【风格头·English】**：

```

```

**工具技巧**：
- Midjourney：效果图加 `--ar 9:16`，图标加 `--ar 1:1`；锁风格用定稿样张 `--sref <图URL> --sw 200`；同批固定 `--seed` 提高一致性
- 即梦/豆包/GPT-4o：上传第 0 批定稿作参考图 + 拼风格头；GPT-4o 系可直接用自然语言长描述
- 透明底（散件）：Recraft 原生支持透明；其余工具纯白底生成后抠图（浅色风格白底最稳）
- 九宫格面板/按钮：AI 直接出可切片九宫格不现实——出**整只组件**透明底图（**无投影无外发光**，否则九宫格拉伸时角部变形），接入时在 Unity Sprite Editor 设 border（角 64/边 32/中心 32 一致）即可，`Image.Type.Sliced` 自动九宫格，**无须物理切成 9 块**（现有 UITheme.Load 即此方案）
- 从整屏效果图里抠组件：不推荐——图内组件带环境光照/投影，抠出边缘脏、颜色被染色；效果图只当风格/布局参考，散件一律单独生成（纯白底 → 抠图）
- 一次生成 4 张选 1，宁缺毋滥；同一界面多态（如格子四态）放同一批出

## 五、逐屏需求详单

> 尺寸均为 1080×1920 画幅下的设计像素（来自现有代码盘点，重搭时布局可微调、信息结构不能丢）。

### A1. 登录｜P0（风格样张）

**定位**：第一眼脸面，传达「欢乐舞台开箱」世界观。
**布局**（自上而下）：大字游戏标题 + 副标题（0,-120 起）→ 中央主视觉：明亮聚光灯下胖萌 Q 版宝箱（现 hero 位 400×400，重做建议放大到 500~600）→ 昵称输入框（480×66）→ 金色大按钮「开始冒险」（400×76）→ 服务器提示小字 → 底部：适龄提示 + 用户协议链接 + 右上角语言切换小按钮。
**动态**：输入框文本、按钮置灰（名为空时）、提示文案。
**提示词·中文**：`登录界面：顶部大字游戏标题与副标题，中央明亮舞台聚光灯下的胖萌Q版金色宝箱主视觉（箱盖微开，金币蹦跳），下方长条昵称输入框与一枚醒目橙色大按钮，底部一行小字与右上角语言切换按钮；暖奶油色到天蓝渐变的明亮背景，云朵与彩旗装饰`
**EN**: `login screen: large game title and subtitle at top, a plump cute chibi golden treasure chest hero under a bright cheerful spotlight with coins bouncing out, an elongated name input field and one prominent orange call-to-action button below, small footer text and a language toggle at top right; light cream to sky-blue gradient background with clouds and pennant decorations`

## 八、交付与接入规范

- **格式**：PNG 透明底（组件/图标）；效果图 JPEG/PNG 皆可（不进包）
- **命名与现管线一致**：文件名即加载地址（`UITheme.Load(name)`）；**大小写敏感**（YooAsset `LocationToLower=0`）
- **进包目录**：`Assets/AssetRaw/UI/`（YooAsset UiSpriteBundle 整目录收集，address=文件名）；**新文件名必须同步登记 `UITheme._atlasOf`**（UITheme.cs:34），否则真机/WebGL 恒 null（编辑器正常，易漏测）
- **首次放入后**：Unity 编辑器打开生成 `.meta`，**.meta 必须随图提交**；真机验证需重新收集 YooAsset bundle
- **九宫格**：面板/按钮交付**整只透明底图**（无投影无外发光），接入时 Unity Sprite Editor 设 border（角 64/边 32/中心 32 一致）即可，无须物理切片；背景底部预留 300px 安全区（顶栏+底按钮遮挡）
- **图内不带文字**（多语言由程序渲染）；战报模板同（品牌文字程序画）

### 重搭工程提示（盘点发现的技术债，重做时一并解决）

1. **全项目无 ScrollRect**：所有列表纯堆叠（好友超 12 截断、背包/排行溢出）——重搭必须引入统一滚动列表组件（含第六章滚动条皮肤）。
2. **无弹窗框架**：所有弹窗各自手写 `CreatePanel`+Destroy，无遮罩栈/层级管理——重搭立 D3 通用确认框 + 弹窗管理器。
3. **DuelPanel/FriendPanel 等大面板不归 UIManager**（直接挂 Canvas、自管销毁）——重搭时纳入统一界面栈。
4. 入口按钮与玩法开关（`ApplyFeatureGates`）联动，重搭大厅时保留该机制。
5. 沿用节点命名约定（`btn_back`/`info_panel/btn_buy` 等 Find 键），重搭 prefab 保持同名可大幅减少绑定代码改动。
